# Play Console — « App content » answers (verified against the code)

An earlier version of this file said « no data collected ». That was WRONG:
both apps send the user's position (`lat`/`lon` on suggestions, building
lookups and reports) and an installation identifier (`X-Install-Id`, which
carries the quota). Anything that leaves the device counts as collected, and
a false declaration is a removal-grade violation.

## Data safety — DATA COLLECTED
| Type | Collected | Shared | Purpose | Required |
|---|---|---|---|---|
| **Location — approximate** | Yes | No | App functionality (centre the map, suggest nearby addresses) | Optional (an address can be typed instead) |
| **Device or other IDs** (installation identifier) | Yes | No | App functionality and fraud prevention (free-report quota) | Required |

- Data is **encrypted in transit** (HTTPS everywhere): yes.
- Users can **request deletion**: yes — contact@confinia.io. Uninstalling also
  destroys the installation identifier, which we cannot recover.
- No advertising or analytics SDK, no third-party sharing, no account required.
